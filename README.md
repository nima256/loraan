# لوران | Loran — Storefront

فرانت‌اند فروشگاه اینترنتی کفش **لوران** (یزد) — فارسی، راست‌به‌چپ، با حالت روشن و تیره.

> **این پروژه فقط فرانت‌اند است.** هیچ بک‌اند، پایگاه داده، درگاه پرداخت یا سامانه پیامکی
> واقعی پیاده‌سازی نشده است. همه داده‌ها ساختگی‌اند و ساختار کد طوری چیده شده که اتصال به
> یک بک‌اند (Node.js/Express یا هر چیز دیگر) بدون بازطراحی رابط کاربری انجام شود.

---

## راه‌اندازی

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # بیلد تولیدی
npm run lint
npm run typecheck
```

نیازمندی: Node.js 20 یا بالاتر.

## اتصال به بک‌اند

سه نقطه اتصال وجود دارد و بقیه کد دست‌نخورده می‌ماند:

1. **`src/lib/api/products.ts`** — همه توابع از قبل `async` هستند. بدنه‌شان را با
   `fetch("/api/…")` جایگزین کنید. هیچ کامپوننتی مستقیم به `src/data` دسترسی ندارد.
2. **`src/store/CartProvider.tsx` و `AuthProvider.tsx`** — منطق داخلی را با فراخوانی API
   عوض کنید؛ رابط Context (که کامپوننت‌ها به آن وابسته‌اند) ثابت می‌ماند.
   - `requestOtp` → `POST /auth/otp`
   - `verifyOtp` → `POST /auth/verify`
   - افزودن به سبد → `POST /cart/items`
3. **`src/types/index.ts`** — قرارداد داده. اگر بک‌اند همین شکل را برگرداند، چیزی نباید تغییر کند.

### نکته‌های مهم مدل داده

- **موجودی روی «تنوع» است، نه محصول.** هر `ProductVariant` ترکیب یک رنگ و یک سایز است و
  `stock` خودش را دارد. کل رابط کاربری (صفحه محصول، سبد، انبار، ماتریس پنل مدیریت) بر همین
  اساس ساخته شده؛ حالت «مشکی/۴۱ موجود، مشکی/۴۲ ناموجود، سفید/۴۲ موجود» حالت عادی است.
- **قیمت‌ها عدد صحیح تومان‌اند.** هیچ‌جا اعشار یا ریال استفاده نشده.
- **هزینه ارسال تیپاکس پس‌کرایه است** و عمداً از `payableOnline` کنار گذاشته شده.
  `OrderTotals` این تفکیک را نگه می‌دارد و در سبد، تسویه، فاکتور و جزئیات سفارش نمایش می‌دهد.
- **وضعیت‌های سفارش** در `src/lib/orders.ts` تعریف شده‌اند: پنج وضعیت اصلی
  (در انتظار پرداخت، در حال آماده‌سازی، بسته‌بندی شد، ارسال شد، تحویل داده شد) تایم‌لاین را
  می‌سازند و وضعیت‌های استثنا (لغو، مرجوعی، بازپرداخت، پرداخت ناموفق، منقضی) بیرون از تایم‌لاین
  نمایش داده می‌شوند.

## دارایی‌های برند

- `public/brand/loran-logo.png` — لوگوی اصلی ارسالی (دست‌نخورده)
- `loran-mark*.png` / `loran-wordmark*.png` — همان لوگو، جدا شده به نشان و لوگوتایپ و در دو
  رنگ برند. با `node scripts/extract-logo-masks.mjs` دوباره ساخته می‌شوند. لوگو بازطراحی نشده؛
  فقط رنگ مرکب آن بین حالت روشن و تیره عوض می‌شود.
- `loran-business-card.png` / `homepage-wireframe.webp` — مرجع طراحی.

### تصاویر محصول

`public/products/*.svg` تصویرهای **برداری موقت** هستند که با
`node scripts/generate-product-images.mjs` ساخته می‌شوند: شش فرم کفش × دوازده رنگ × چهار زاویه،
همگی مربعی (۱:۱) و با قاب‌بندی یکسان — به همین دلیل شبکه محصولات هنگام تغییر رنگ یا صفحه نمی‌پرد.

برای جایگزینی با عکس واقعی: فایل‌ها را با همین نام‌ها در `public/products/` قرار دهید،
یا مسیرها را در `src/data/catalog.json` (میدان `colors[].images`) عوض کنید. هیچ کامپوننتی
مسیر تصویر را hard-code نکرده است.

## تصمیم‌های طراحی

- **دیزاین سیستم در `globals.css`.** رنگ‌ها توکن معنایی‌اند (`--surface`، `--fg-muted`،
  `--primary`)، نه کد رنگ خام در کامپوننت‌ها. حالت تیره یک وارونه‌سازی نیست: خنثی‌ها گرم‌اند
  و رابطه «کرم روی زرشکی» لوگو حفظ شده. همه جفت‌های متن/پس‌زمینه دست‌کم ۴٫۵:۱ کنتراست دارند.
- **رنگ برند جیره‌بندی شده.** `#9A1C21` فقط برای اقدام اصلی، تخفیف و وضعیت فعال؛ `#EEE6DD`
  فضای گرم پس‌زمینه را می‌سازد. در هر ناحیه صفحه فقط یک دکمه «اصلی» وجود دارد.
- **موبایل بازطراحی شده، نه کوچک‌شده.** هدر موبایل ۵۶px است، ناوبری پایین پنج مقصد اصلی را
  دارد، فیلترها در شیت پایین باز می‌شوند و دکمه خرید چسبان فقط وقتی ظاهر می‌شود که دکمه اصلی
  از دید خارج شده باشد.
- **نمودارها تک‌رنگ‌اند.** هویت با برچسب مستقیم و متن محور منتقل می‌شود نه با رنگ، بنابراین
  نمودارها برای کاربران کوررنگ و در چاپ هم خوانا می‌مانند. هر نمودار نمای جدولی دارد.
- **دسترس‌پذیری.** فوکوس دیدنی در کل سایت، ناوبری کامل با صفحه‌کلید، تله فوکوس و بازگشت فوکوس
  در همه لایه‌های شناور، اندازه هدف لمسی حداقل ۴۴px، احترام به `prefers-reduced-motion`، و
  خطاهای فرم که با `aria-describedby` به فیلد وصل می‌شوند.
- **نامک محصول‌ها انگلیسی است** (`/product/loran-sepehr-562`) تا در اشتراک‌گذاری، لاگ و API
  به رشته درصدی ناخوانا تبدیل نشود. نام فارسی در عنوان صفحه و `<h1>` می‌آید.

## ابزارهای توسعه

```bash
node scripts/generate-catalog.mjs         # ساخت ۱۰۰ محصول ساختگی (قطعی و تکرارپذیر)
node scripts/generate-product-images.mjs  # ساخت تصاویر محصول
node scripts/extract-logo-masks.mjs       # جدا کردن نشان و لوگوتایپ از لوگو (نیازمند Pillow)
node scripts/audit.mjs 390 --auth /shop   # بررسی سرریز افقی، هدف‌های لمسی کوچک و خطاهای کنسول
node scripts/shoot.mjs out 390 full /shop # اسکرین‌شات (با ‎--dark برای حالت تیره)
node scripts/flow.mjs out 390             # پیمایش کامل مسیر خرید و عکس‌برداری از هر مرحله
```
